# ライセンスと利用範囲

## 既定は私的使用

依頼者本人が読むための和訳は **私的使用のための翻訳** として作成してよい。根拠は日本の著作権法第 30 条（私的使用のための複製）と第 47 条の 6 第 1 項第 1 号（私的使用のための翻訳）である。

このとき、次をしてはならない。

- ライセンスが CC 系でないことを理由に全文翻訳を断る
- 全文 PDF の代わりに要約や解説ノートを作る
- 「翻訳してよいか」をユーザーへ問い直して作業を止める

代わりに、成果物へ利用範囲を明示する。PDF の 1 ページ目と作業記録の両方に次を書く。

- 原著者、原題、原著 URL（`arXiv:XXXX.XXXXX`）
- 原著ページに表示されているライセンス名と URL
- 本 PDF が原著の翻訳（派生物）であること
- 「私的使用のための翻訳であり、再配布・公開・第三者への提供は行わない」旨

PDF では 1 ページ目の枠付きボックスに置くと見落としにくい。

```tex
\begin{center}
\fbox{\begin{minipage}{0.92\textwidth}\small
\textbf{出典}\quad Author A, Author B, ``Original Title,'' arXiv:XXXX.XXXXX, 20XX.\\
\url{https://arxiv.org/abs/XXXX.XXXXX}\\
\textbf{原著ライセンス}\quad arXiv.org perpetual, non-exclusive license 1.0\\
本書は上記論文の日本語訳（派生物）であり、私的使用のために作成した。再配布・公開は行わない。
\end{minipage}}
\end{center}
```

## 再配布・公開を求められた場合だけ判定する

ユーザーが公開、社内共有、第三者への提供を明示したときに限り、原著ページのライセンス表示で判定する。

| 原著ライセンス | 翻訳の再配布 | 対応 |
| --- | --- | --- |
| CC0 1.0 | 可 | 出典を表示する（義務ではないが記載する） |
| CC BY 4.0 | 可 | 出典表示と、改変（翻訳）した旨の明示が必要 |
| CC BY-SA 4.0 | 可 | 上記に加え、同一ライセンスで公開する |
| CC BY-NC-SA 4.0 | 非営利に限り可 | 非営利であることを確認し、同一ライセンスで公開する |
| CC BY-NC-ND 4.0 | 不可 | 翻訳は改変にあたるため配布できない |
| arXiv.org perpetual, non-exclusive license 1.0 | 不可 | 投稿者が arXiv に与えた配布許諾にすぎず、第三者の翻案・再配布は許諾されない |
| ライセンス表示なし | 不可 | 原則として権利者の許諾が必要 |

「不可」に該当する場合だけ、次のいずれかを提示する。

1. 私的使用の範囲に留める（全文訳は作るが配布しない）
2. 独自記述の要約・解説ノートへ切り替える（原文の表現を再現しない）
3. 原著者へ許諾を求める

判断と選んだ対応を作業記録へ書く。

## 記録の対象

作業記録には次を残す。

- 取得したライセンス表示の原文（URL 込み）
- 私的使用として作成した旨
- 図版を改変した場合はその範囲
- 参考文献を原題のまま残した旨
