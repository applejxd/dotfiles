# `exp compare` の計算と限界

A（基準）と B（変更後）の、同じ指標・同じ split の、成功した実行の値を比べる。差は **B − A**。

## 計算

- **記述統計**: n・平均・標準偏差（n−1 で割る）・中央値・最小・最大。
- **差の平均の 95% 信頼区間**: ブートストラップ（各群を復元抽出して平均の差を `--boot` 回〈既定 10000〉求め、2.5% と 97.5% の点を取る）。
  乱数の種は入力の内容（指標名・両群の値・回数）のハッシュから決めるので、同じ入力なら同じ区間になる（再現可能）。
- **効果量**: Cohen's d（合併標準偏差。分散が 0 か n < 2 なら `-`）と、A の平均に対する相対変化（%）。
- **Mann–Whitney U 検定**（両側）: 同順位は平均順位。2 群の合計 n が 40 以下なら、順位和の**正確な並べ替え分布**で p 値を出す
  （同順位があっても、平均順位を 2 倍した整数で数えるので正確）。それより大きいときは、同順位補正と連続性補正つきの**正規近似**。どちらかを出力に表示する。
- **判定**: 区間が 0 を含まず、かつ p < 0.05 のときだけ「改善」「悪化」（`direction` が `max` なら増加が改善、`min` なら減少が改善）。
  それ以外は「差は見えない」。**どちらかの群の n が 5 未満なら、警告を出し、判定は「判断できない」**にする。

## 限界

- **独立性の仮定**: 各実行は独立とみなす。seed を変えても共通の要因（同じデータ・同じ起動直後の状態・熱による低下・ほかの負荷）が残ると、実際より差が確かに見える。
  実行の順序を A・B で交互にする、測定中に別の負荷をかけない、が対策。
- **n が小さいときの検出力**: n=5 対 5 の Mann–Whitney で出せる最小の p は約 0.008。差が小さい変更は、5 回では検出できないことが多い。
  「差は見えない」は「差が無い」ではない。区間の幅を見て、必要なら seed を増やす。
- **多重比較**: 多くの変更を比べると、偶然に p < 0.05 になるものが混ざる。20 回比べれば 1 回は偶然に出る。
  採用した変更は、`val` で 1 度だけ確かめる（予算を守る）。同じ比較を、seed を足しながら有意になるまで繰り返さない（早期終了の偏り）。
- **外れ値と分布の形**: 平均の差の区間は外れ値に弱い。中央値・最小・最大も見る。
- **標準偏差の見積もり**: n が小さいと標準偏差自体が不安定。
