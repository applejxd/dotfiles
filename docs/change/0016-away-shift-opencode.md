## 現在地

着手前。2026-10-07 の棚卸し（applejxd 限定にすべき設定の洗い出し）の中で
話題に上がり、別案件として積んだ。

その時点で気づいていた点（既存の調査で分かっている部分を除き、未検証）:

- `SKILL.md:23` は「autopilot / 自動承認モードで動いていること」を前提に
  している。OpenCode で同じ前提が成り立つか、どのエージェントで動かすのかは
  決まっていない
- frontmatter の `allowed-tools`（`SKILL.md:4`）は Claude Code 向けの項目である。
  OpenCode v2.0.14 では読み捨てられることが既存の調査で分かっている
  （[skill の frontmatter の調査](../research/opencode/skill-frontmatter.md)）。現行版での扱いと、
  away-shift の動作への影響は確かめていない
- away-shift の事前検査（`scripts/executable_preflight.py`）は、コマンドの可否を Claude Code の
  hook（`~/.claude/hooks/check_bash.py`）に問い合わせて決めている。OpenCode の permission や
  guide plugin の判定とは別物で、OpenCode で「確認が要らない」と判定した操作が実際には
  確認になる（または逆）ことがありうる（未検証）
- 作業範囲は `./.tmp/away-shift/` に限られる（`SKILL.md:3`）。学習ジョブの
  再開では、本来のチェックポイントやログの場所に書く、プロセスを起動し直す
  といった範囲外の操作が要りがちで、範囲外として止まる可能性がある
- 会社 PC では、無人でエージェントを動かすことが社内規則で許されるか、
  長時間の反復で Bedrock の利用料がどこまで積み上がるかを確かめる必要がある
