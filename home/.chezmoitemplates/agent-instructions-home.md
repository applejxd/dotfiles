# 自宅の機だけの指示

## 開発中の Web サービス

- 開発中の Web サービス（開発サーバ・ダッシュボード・API の試作など）は、Tailscale が使える機（`tailscale status` が成功する）では、**tailnet の中だけに公開する**のを原則にする。アプリは `127.0.0.1` で待ち受け、`tailscale serve --bg <ポート>` で出す。`0.0.0.0` での待ち受けと、インターネットへ出す `tailscale funnel` は、利用者が明示したときだけ。tailnet の端末は利用者本人のものだけなので、tailnet への公開に、認証の有無や中身を理由にした事前の確認・警告は要らない（利用者の方針。2026-11-17）。
- 公開の手順（構文の確かめ方・WSL の機での `tailscale.exe`・既存の https ポートを上書きしない・片付け）は `tailscale-serve` スキルを読む。
