# 個人用カスタム指示

## 応答

- ユーザーへの説明は日本語で書く（コードやコミットメッセージ自体は対象外）。

## 環境の前提

- Python で依存管理ツールが決まっていないリポジトリでは `uv` / `uvx` を使う。

## 停止と報告

- rules や承認プロンプトで拒否されたら、拒否条件を満たす別手段に切り替える。条件自体を回避する迂回（コマンドの分割・偽装、`--no-verify` などのバイパス）はせず、手段が無ければ停止して報告する。

## 検証

- 完了を報告する前に、リポジトリで定義されているテスト / lint / ビルドを探して実行し、出力を根拠として示す。見つからない場合やサンドボックスで実行できない場合は未検証と明記する。
- 実行していないチェックの結果を推測で書かない。
