# 台本(narration.txt)の書き方

台本は、字幕と読み上げの両方になる。次の約束で書くと、直す往復が減る。

## 基本

- **字幕と読み上げは同じ文。** 話し言葉で、1 行 1 文を目安に書く
  (長い行は字幕が 2 行を超える。`narration_check.py` が注意する)
- **字幕は正式名称で書く。** 英字・数字・漢字のまま書き、読み(カタカナ)を
  字幕に書いて音を合わせない(`スラマー` ではなく `SLAM-MER`)。
  読みは辞書(`yomi.json`)で直す
- **日本語と英数字の間の空白は、入れても入れなくてもよい。** 字幕では読みやすく、
  読み上げでは ENGINE に渡す前に自動で除かれる(息継ぎの間にならない)。
  英数字同士の空白(`Sparse Voxel Grid`)は残る
- **数式・記号は言い換える。** `Q_3D = Q_T ∪ Q_S` ではなく
  「キュー三次元は、時間と空間の和集合」。検査が TeX 記号を指摘する

## 読み上げでどうなるかを確かめる

| 知りたいこと | 使うもの |
| --- | --- |
| 読み上げで何が変わるか | `narration_check.py --show-spoken`(行ごとに規則名つき) |
| 変えない(厳密にする) | `narration_check.py --strict`(違いがあれば終了コード 1) |
| ENGINE が実際にどう読むか | `readings.py`(「読み上げ文」を併記し、仮名を出す) |
| 語の読みを直す | 確認画面の「読み」タブか `yomi.py set 表記 読み` |

整形の規則と、増やすときの手順は `references/yomi.md` の
「読み上げ前の整形」にある。規則は名前つきの表(`scripts/speech.py` の `RULES`)で、
試験(`tests/test_speech.py`)が、表の例と文書の一致を確かめる。

## 避けること

- 字幕に読みを書く(上の約束)。辞書に表記があるのに行へカタカナの読みだけを書くと、
  検査が指摘する(`--allow-kana` で意図したカタカナ表記を許す)
- 規則の例にない整形を、推測で足す。足すときは先に実エンジンで影響を確かめる
