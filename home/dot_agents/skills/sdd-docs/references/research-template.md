# 調査記録テンプレート

`docs/research/<topic>.md` の雛形。書き方は [SDD 文書の書式](markdown-style.md)、記録の単位は対象リポジトリの `docs/research/index.md` を参照する。
図表が中心なら、別の Markdown ファイルを作らず [自己完結 HTML の雛形](research-report.html.tpl) を使ってよい。

## 約束

- 1 記録は 1 つの問い。測り直し・掘り下げは、同じファイルへ日付つきの節（`記録 E2 — YYYY-MM-DD` など）として足す。問いが変わったら新しい記録にする
- 観測日と一次情報の URL を必ず書く
- 結論を先に書く。読む人はたいていそこだけ見る
- 過去の観測・結論を書き換えない
  - 訂正・撤回は新しい節として足し、元の節の冒頭に訂正先への案内を置く
  - 記録は割らず、見出しの文言も変えない（案件・仕様・コードが節番号と見出しで参照している）
- 後の観測や現行の仕様と食い違ったら、ファイルの冒頭に `> **後続の観測**: …` / `> **現行の仕様**: …` の案内を付ける
- 未実施・失敗・不明を区別する。推測には「推測」と明示する
- 経緯を物語にしない。測った順に並べず、結果を表にして、考察は箇条書きにする
