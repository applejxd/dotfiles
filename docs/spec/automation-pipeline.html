隔離スモーク ＋ 2 段防御ロールバック
A. main 昇格ゲート（promote-main.yml） 手動起動＋人承認
  • workflow_dispatch で起動 → 3 OS（Ubuntu / Windows / macOS）で scripts/isolated_smoke.py を並列実行
  • 使い捨て HOME に chezmoi init → 2 回 apply --exclude scripts,externals → 残差分 0 件 ＋ Pi JSON・gitconfig・Vim・PowerShell / bash / zsh 起動スモーク
  • 3 OS 全通後に protected-path-approval 承認 → develop を main へ昇格
B. 端末安全更新（scripts/chezmoi_safe_update.py） 自動ファイル切り戻し
  • 第 1 段（実機無傷プレフライト）: 更新先 SHA を一時 worktree ＋ isolated_smoke で事前検証。失敗時は実機 $HOME に一切触れず停止
  • 第 2 段（自動切り戻し）: 本番 apply（恒久 source から実行）または実機 check-dest 失敗時、直前の正常 SHA（last_good_sha）へ戻して管理ファイルを自動復元
  • 副作用境界の明示: run_* が走っていた場合はパッケージ・OS 設定等の外部副作用が自動では戻らない旨と対象スクリプト一覧を警告出力
