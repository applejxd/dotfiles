# Markdownセルの記述テンプレート

## 基本方針

コードを読まなくても次の4点が分かるようにする。

- **使用データ**：どのURL・どのファイル・どの範囲か
- **前処理パラメータ**：値と**単位**（文字数かトークン数か等）
- **作成するDB・成果物**：インメモリか永続か、保存先はどこか
- **関数・クラスの入出力**：入力の型と意味、処理の要点、出力の型と意味

## テンプレート1：通常のセル（散文2〜4文）

「何を入力に、何をして、何が出力されるか」＋特筆すべきパラメータの意図。

```markdown
質問をリトリーバーへ渡して検索します。次の2セルは、検索の実行と、返ってきた
`Document` の件数の確認です。`k=1` を指定しているので件数は1になります。
```

## テンプレート2：インデックス構築・データ読み込みセル

散文で概要を述べたうえで箇条書き。

```markdown
Webページを読み込み、チャンクへ分割します。

- データ：<記事名>（<URL>）
- 前処理：<絞り込み条件。例: SoupStrainer で post-content のみ抽出>
- 分割：<splitter> / chunk_size=N, chunk_overlap=M（**文字数**基準）
- 出力：`変数名` = <型・意味>（表示される数値がチャンク数）
```

保存先を伴う場合：

```markdown
- 入力：`chunks`（前のセルで分割した `Document` リスト）
- DB：Chroma。`persist_directory` を指定していないため**インメモリ**で、
  ノートブックのプロセスが終わると消えます
- 出力：`retriever` = 既定設定（類似度検索・`k=4`）のリトリーバー
```

## テンプレート3：自作関数・自作クラスのセル

```markdown
`関数名()` は<一言で役割>。

- 入力：<型と意味>
- 処理：<アルゴリズムの要点。なぜその実装なのか>
- 出力：<型と意味>
```

例：

```markdown
- 入力：検索結果のリストのリスト（クエリごとに1つのランキング）
- 処理：`dumps` で `Document` を文字列化して集合演算で重複を除きます
  （`Document` は直接ハッシュできないため）
- 出力：重複を除いた `Document` のリスト
```

**通常と型が違う場合は明示する**（読み手が最も間違えるポイント）。

```markdown
戻り値が `(Document, score)` のタプルのリストであり、通常のリトリーバー出力
（`Document` のリスト）と**型が違う**点に注意します。
```

## テンプレート4：共通部品セル（ノート冒頭）

`with app.setup:` は marimo 上で折りたたまれて見えないため必須。

```markdown
## このノートブックの共通部品

冒頭の `with app.setup` ブロック（marimo上では折りたたまれています）で、以下の
共通部品を定義しています。各セルはこれらを繰り返し使います。

- `ヘルパー名()`：<役割>。<特筆すべき設定とその理由>
- `ヘルパー名()`：<役割>

<このノート固有の前提があれば書く。例：このノートブックではベクトルストアを
作りません>
```

## テンプレート5：複数セルのグルーピング

些細なセルは直前のMarkdownでまとめて言及する。

```markdown
続く3つのセルで、生成を手動で組み立てます。

1. `chat_model`：チャットモデルを用意する
2. `chain`：プロンプトとモデルを `|` でつなぐ
3. 実行：検索結果を `context` として渡す

戻り値は `StrOutputParser` を通していないため、文字列ではなく `AIMessage` です。
```

**実際のセル数・順序と一致しているか必ず確認する。**

## 書いてはいけないこと

- **推測**：既定値・次元数・挙動を確認せずに書かない
- **断定できない一致**：近似手法の結果を「一致します」と書かない。
  「この規模では一致しますが、大きくなると差が出ることがあります」とする
- **環境変数で変わる値の固定表記**：「1536次元になります」ではなく
  「モデルによって次元数は変わります」
- **冗長な重複**：近接するセルで同じ説明を繰り返さない

## 文体

- です・ます調、簡潔に
- コード識別子はバックティックで囲む
- 既存ファイルの文体に合わせる（新規に決めない）
