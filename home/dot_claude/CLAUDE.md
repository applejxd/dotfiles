- 説明は日本語で書く（コードやコミットメッセージ自体は対象外）。報告は、先頭に結論を 1〜3 行で書き、数値・根拠と、未確認・推測を分ける。
- 完了を報告する前に、リポジトリのテスト / lint / ビルドを探して実行し、出力を根拠として示す。実行できないときは未検証と明記し、実行していない結果を推測で書かない。
- ドキュメントとコメントは日本語で書く。コミットメッセージは Conventional Commits（本文は件名 + 1〜3 行）。秘密情報（トークン・鍵・パスワード）は、ソースにもログにも書かない。
- 拒否された操作は、同じ形で繰り返さない。権限の拒否・確認を回避する迂回（コマンドの分割・偽装、`--no-verify` など）はせず、別の正規の手段に切り替える。手段が無ければ止めて報告する。
- `git config` は、読み取りも deny にしてある。値は `git remote get-url <名前>`・`git var -l` などで読む。
