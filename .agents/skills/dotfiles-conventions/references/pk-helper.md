# 利用者に実行してもらう補助スクリプト

- **`pk <話題> [引数]` の形で示す。** 入口は `.tmp/keep/<話題>/run.sh`（無ければ唯一の `*.sh`）。`sh <長い絶対パス>` は使わない（`pk` は `chezmoi apply` で配備。未配備の機械では絶対パスでよい）。入口の先頭コメントの 1 行目は `pk` の一覧に出る説明として書く。話題名は短く覚えやすく（[詳細](../../../../docs/spec/development.md#補助スクリプトの短い入口pk)）。
- **利用者の端末で止まらない書き方にする**: 入口の先頭（`set -eu` の次）に `export GIT_PAGER=cat PAGER=cat` を置く（`git log`・`git branch` が pager で止まり、`q` を押させない）。コマンドを会話に貼って実行させるなら、行末に `#` のコメントを付けず、1 行を短くする（zsh の対話シェルは `#` をコメントにせず、携帯端末は長い行を折り返して別のコマンドにする。2026-11-15 に実際に起きた）。複数の手順は `pk` の入口にまとめる。
